# Brain Quest Adventures

A learning app for kids (ages ~5 and ~8): math, reading, science and geography,
with quizzes, interactive world/US maps, stars, levels and badges.

Current version: v1.9.

- `index.html` – the complete app (open it in a browser). This is the published version.
- `src.html` – the same app without the embedded map data (easier to read/edit).
  The map shapes are inserted where `/*GEO*/` appears.
- `apple-touch-icon.png`, `brain-quest-icon.png`, `brain-quest-qr.png` – icons and QR code.

Live version: https://claude.ai/artifact/RdASiVbrDb1dFM8BgLRsY9
Built as a single self-contained HTML page (no build tools needed).
Progress saves in the browser and, when opened on claude.ai, to the owner's Claude account.
